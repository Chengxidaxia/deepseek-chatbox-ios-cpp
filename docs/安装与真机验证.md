## 安装

ad-hoc 签名**不能直接双击安装**，必须用带重签能力的工具装：

1. **Sideloadly**（Windows/macOS 都可）
   - 拖入 `ChatboxIOS-adhoc.ipa`，填自己的 Apple ID
   - 它会用你的免费开发者证书重签后安装
   - 免费证书 **7 天过期**，到期需重装；付费开发者账号 1 年

2. **AltStore / SideStore**
   - 装好后把 ipa 拖进去，同样走重签

3. **Xcode 手动重签**
   ```bash
   unzip ChatboxIOS-adhoc.ipa
   # 在 Xcode 里新建一个空工程，把 Payload/ChatboxIOS.app 拖进去，
   # 设置自己的 Team，Product > Archive > 导出
   ```

装完首次启动会被拦（"未受信任的开发者"）：
`设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID`

## 真机验证清单

本机只跑过 `ctest`（270 项断言，纯逻辑层）和云编译（能编过、0 告警）。
**下面这些一次都没在设备上验过**，逐项打勾：

### 基础

- [ ] 冷启动能进会话列表，不闪退
- [ ] 首次进设置页填 API Key → PIN 加密 → 杀掉重开还能解锁
- [ ] 发一条消息能流式返回（SSE 逐字出）
- [ ] 断网发消息有明确错误提示，不是静默失败

### 新增：真分词器（本版重点）

- [ ] 让模型调 `token_count`，返回的 Token 数与 API `usage` 对得上
- [ ] 首次调用 `token_count` 的耗时（要读 3.91 MB 词表 + 建 12.8 万条哈希表，
      预期几十到一两百毫秒；如果明显卡顿需要改成后台线程预热）
- [ ] 内存峰值（词表 + 哈希表常驻，预期 +40~60 MB；在 Xcode Instruments 里看）
- [ ] `detail=true` 能返回 id 与片段

### 联网工具

- [ ] `fetch_url` 抓一个 **http**（非 https）站点——ATS 只对 NSURLSession 生效，
      libcurl 走裸 socket 应该不受限，但要实测确认
- [ ] `fetch_url` 抓中文站点，GBK 页面能正确转码（依赖 `-liconv`）
- [ ] `web_search` 实际返回结果（三级降级：bing-rss → bing-html → 360）
- [ ] `port_check` 首次调用会弹「本地网络」权限；拒绝后再调用有降级提示，不崩
- [ ] `dns_lookup` / `local_ip` 在 Wi-Fi 与蜂窝下都正常

### 其他

- [ ] 续写（「继续生成」按钮）走 beta 端点能正常接上
- [ ] ASR 按住说话 → 松手上传 → 转文字（整段上传，官方不支持流式）
- [ ] TTS 朗读有声音
- [ ] 图片附件能选、能发、能显示
- [ ] 二维码工具生成的 PNG 能显示、长按能存

## 已知限制

- **未做真机验证**：上面清单全是待验状态
- ad-hoc 签名，需重签才能装，免费证书 7 天过期
- `cmd_run` 不可用（iOS 沙箱不允许执行本机命令），40 个工具里唯一缺的
- 侧边栏用导航栈 push，没做成官方那种抽屉
- 不支持流式 ASR（官方未开放）
