## P1 · `aes_crypto`

- **现状**：`tools.cpp:643` 直接 `return fail("AES 工具需 Web Crypto…")`。这句是 Web 版注释照抄，**理由不成立** —— `libcrypto`（OpenSSL）已在 CMake 链接列表里。
- **要做**：用 `EVP_*` 实现 CBC / GCM / ECB，key 与 iv 支持 hex / base64 两种编码；GCM 额外返回 auth tag；PKCS#7 填充。
- **参照**：`tools-core.cjs:1581`（Web 版走 Web Crypto，参数语义照抄，实现换 OpenSSL）。
- **注意**：iOS 侧 OpenSSL 是 vcpkg 静态库，需确认 `EVP_aes_256_gcm` 等符号在 arm64-ios triplet 里可用（大概率可用）。
- **验收**：与 Web 版对同一明文/key/iv 互相加解密，密文逐字节相同（CBC/ECB），GCM 密文 + tag 相同。

## P2 · 网络 / 系统类 6 个（`cmd_run` 除外）

这 6 个都不需要新依赖，`libcurl` 已链接。真正要处理的是「网络行为在 iOS 上的约束」，逐条写清：

| 工具 | 参照行号 | 关键约束 |
|---|---|---|
| `http_request` | `tools-core.cjs:1240` | **ATS**：当前 `Info.plist` 的 `NSAllowsArbitraryLoads = false`，只对 DeepSeek 域开了例外。libcurl 走自有 socket 通常不经 ATS，但**需实测确认**（未确认）。若实测被拦，二选一：只允许 https，或加 `NSAllowsArbitraryLoadsInWebContent` / 域例外 |
| `fetch_url` | `tools-core.cjs:1059` | 同 ATS；另需正文提取（去 script/style/导航），照搬 Web 版正则链即可 |
| `web_search` | `tools-core.cjs:1042` | 同 ATS；抓 Bing HTML 需带 `User-Agent`，并处理反爬返回空结果的降级提示 |
| `dns_lookup` | `tools-core.cjs:1207` | `getaddrinfo` 可用，无权限弹窗 |
| `port_check` | `tools-core.cjs:1223` | POSIX socket 可用；**iOS 14+ 扫局域网会弹「本地网络」权限**，需在 `Info.plist` 加 `NSLocalNetworkUsageDescription`，并给超时上限（建议 ≤3s） |
| `local_ip` | `tools-core.cjs:1259` | `getifaddrs` 可用；只能看到 Wi-Fi / 蜂窝接口，拿不到运营商侧信息 |

- **共用改造**：把「联网/系统能力限制」那条统一拦截分支（`tools.cpp:677`）拆开，只保留 `cmd_run`。
- **验收**：6 个工具在真机各跑一次；`port_check` 首次触发权限弹窗且拒绝后能优雅降级。
